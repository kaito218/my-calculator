## iPhoneでホーム画面に追加する方法
このアプリは、HTTPSで公開したページをSafariで開くとホーム画面に追加できます。

1. GitHub Pages / Netlify / Cloudflare Pages などにこの4ファイルをアップロード
2. iPhoneのSafariで公開URLを開く
3. 共有ボタンをタップ
4. 「ホーム画面に追加」を選択
5. ホーム画面から起動

ホーム画面から起動すると、通常のWebページよりアプリっぽく表示されます。
